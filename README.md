# 桌面运维全能学习导师

一款面向桌面运维 / IT Helpdesk 学习与日常知识整理的课程型学习应用。应用内置桌面运维系统课程，并提供课程管理、章节学习、划线批注、间隔复习、故障案例沉淀、术语整理、学习统计、资料导入导出和朗读辅助等功能。

本仓库将原始 HTML 应用封装为 Android APK：**HTML、CSS、JavaScript 页面主体作为本地资源打包，不重写原页面结构和视觉样式**，通过 Android WebView 提供手机端运行入口。

## 一、应用功能

### 1. 桌面运维系统课程

内置「桌面运维全能学习导师」课程，按循序渐进的学习路线组织为 **7 个模块、30 章**。课程从基础知识逐步延伸到企业桌面运维常见工作场景，覆盖：

- Windows 桌面系统基础与常见管理操作
- 计算机硬件、终端设备与外设基础
- TCP/IP 网络基础及常见网络问题
- Active Directory（AD）域、域用户与计算机管理
- DNS、DHCP、身份认证等域环境相关基础
- 组策略（GPO）、文件共享与权限管理
- Helpdesk 高频支持场景、分层排障方法与 PowerShell 相关内容

章节内容围绕概念理解、实际操作、命令与预期输出、常见错误与避坑提示组织，并配有互动练习。课程中还提供知识依赖关系提示，帮助理解先修知识和章节之间的联系。

### 2. 课程管理与课程导入

- 查看和管理课程，可新增课程并编辑课程信息。
- 支持调整课程名称、简介、封面 / 图标等课程展示信息。
- 课程导入分为「文字」「视频」「语音」三个入口。
- 文字课程支持从 JSON、Markdown、CSV 文件导入，也可粘贴文本内容导入。
- 视频课程和语音课程支持从文件夹选择媒体文件，也支持选择单个文件；可按文件名称或时间排序。
- 导入前可查看识别结果，再确认创建课程。
- 导入课程会作为独立课程加入课程列表；同名课程会自动处理为副本名称。

说明：视频、音频文件本身是设备上的媒体文件，不包含在个人数据 JSON 备份中。更换设备或重新导入备份后，需要重新选择 / 连接相应媒体文件。

### 3. 章节学习与媒体播放

- 按课程、模块和章节浏览学习内容。
- 记录章节学习状态与完成进度。
- 视频 / 音频课程使用独立媒体播放页面，可在课程章节间切换。
- 章节阅读、复习、划线等学习页面会累计学习时长。
- 离开学习页面或连续 2 分钟无操作时，学习计时暂停，减少无效时长统计。

### 4. 朗读与阅读辅助

- 章节文字可启动朗读，并提供暂停、继续和停止控制。
- 朗读设置支持选择可用的语音引擎 / 音色，并调整语速。
- 根据设备实际可用情况使用系统语音或在线语音服务。
- 系统语音或在线语音不可用时，应用会回退到专注阅读模式，避免朗读服务不可用导致章节无法继续阅读。
- 在线语音需要网络连接；使用在线语音时，待朗读文字会发送给对应语音服务。系统语音模式不需要将文字发送到在线语音服务。

可用音色和引擎取决于设备、浏览器 / WebView 环境及相关服务的实际支持情况。

### 5. 今日学习、复习队列与学习计划

- 「今日学习」用于进入当前课程章节，查看和推进学习内容。
- 「复习队列」采用间隔提取复习节奏，包含 1、2、4、7、15、30 天等复习间隔。
- 通过主动回忆进行复习；答错的条目会按应用内规则重新安排复习节奏。
- 学习进度与章节状态联动，便于持续跟踪课程完成情况。

### 6. 划线、重点摘录与备注

- 在章节正文中选择重点内容并添加划线标记。
- 支持不同颜色、线型和备注。
- 可按课程查看和整理已保存的划线内容。
- 划线记录保留原文、样式、标签、备注和时间信息。
- 可将划线与备注汇总导出，用于个人运维笔记和复习清单。

### 7. 知识详解、术语手册与故障案例库

- **知识详解**：围绕课程知识点查看补充说明。
- **术语手册**：整理和维护运维术语，支持数据导入导出。
- **案例库**：沉淀故障处理过程，支持按结构整理案例，并可导出 TXT / CSV 等资料。
- 课程学习、划线摘录、术语和故障案例可互相补充，形成个人知识资料库。

### 8. 排障手册与学习进度

- 提供排障方法与操作提示，辅助建立分层定位问题的思路。
- 展示章节完成情况、学习路线和课程整体进度。
- 支持查看每日学习记录及相关课程学习情况。
- 课程页提供学习节奏、知识资料库、方法与进度等快捷入口；快捷入口可进行个性化配置。

### 9. 学习日历与统计

- 按日查看学习记录。
- 查看每日学习时长、学习课程和章节进度。
- 学习时长在阅读章节、复习、划线等学习页面自动记录。
- 通过日历和进度视图回顾学习节奏与持续情况。

### 10. 个人资料、主题与界面设置

- 设置个人头像、昵称和个人简介。
- 支持应用内不同界面风格，以及亮色 / 暗色显示模式。
- 支持主题色和外观相关设置。
- 支持课程快捷入口配置。
- 页面采用响应式布局，原 HTML 同时包含桌面和移动端适配样式。

### 11. 数据备份、导入与导出

应用提供课程资料与个人学习数据的导入 / 导出能力，常用格式包括 JSON、Markdown、CSV，以及适用于摘录的 TXT。

可备份或导出的内容包括：

- 课程内容与章节学习手册
- 学习进度、章节状态、学习日期、学习时长与学习路线
- 划线原文、颜色 / 线型、标签、备注和时间
- 故障案例与术语资料
- 个人头像、昵称、主题、主题色、快捷入口和朗读设置等个人偏好

支持导入前预览，并按功能选择合并或覆盖等导入方式。整门课程可导出为可读的 Markdown 或结构化数据；个人数据可导出为 JSON，以便在其他设备恢复。

**重要：** 视频 / 音频媒体文件本身不会被写入个人数据 JSON。备份前建议确认已导出需要保留的学习数据；更换设备、清理应用数据或浏览器存储前，请先完成备份。

## 二、数据保存与隐私说明

- 原始 HTML 应用以本地单文件应用方式运行，学习状态、划线、案例、术语和个人设置主要保存在当前应用 WebView 的本地浏览器存储中。
- 本 Android 包使用本地 assets/index.html 作为页面入口，并通过 AndroidX WebKit 的本地资源加载机制提供安全的本地 HTTPS 页面来源，以支持 Web 存储能力。Android 原生桥接层补齐了 WebView 不完整支持的系统文件夹选择、媒体流读取、系统 TTS、剪贴板和文件保存能力。
- 本地学习数据不会因为构建 APK 就自动同步到云端或其他设备。
- Android 版优先使用手机系统 TextToSpeech，可读取设备实际提供的音色并调整语速；不可用时仍可使用应用内在线语音来源或专注阅读。选择在线语音功能时，朗读文本会按该功能说明发送到对应在线语音服务；使用系统语音时不需要在线发送朗读文本。
- 卸载应用、清除应用数据或更换设备可能导致本地数据无法继续访问，请提前导出备份。

## 三、Android 版本与实现方式

| 项目 | 配置 |
|---|---|
| 应用名称 | 桌面运维全能学习导师 |
| Android applicationId | com.xiaosi555.deskops |
| 最低 Android 版本 | Android 6.0（API 23） |
| 编译 / 目标 SDK | API 35 |
| Java | 17 |
| 页面容器 | Android WebView + Android 原生能力桥接 |
| 本地页面 | app/src/main/assets/index.html |
| 本地资源加载 | AndroidX WebKit WebViewAssetLoader |
| 文件夹 / 文件访问 | Storage Access Framework（SAF） |
| 媒体播放 | 本地流式读取，支持 HTTP Range 分段请求 |
| 系统朗读 | Android TextToSpeech |
| 页面技术 | HTML + CSS + JavaScript |

Android 外壳负责启动本地 HTML、启用 JavaScript 与 DOM Storage、通过 SAF 选择文件 / 文件夹、向 WebView 提供媒体流、提供系统 TTS、剪贴板和系统保存对话框，并将手机系统返回键交给 HTML 应用自身的导航栈处理。应用界面的主体仍由原始 HTML 页面负责；本次兼容性修复未重做各主题的 CSS 版式，原主题色、亮暗模式和页面风格仍由原 HTML 控制。

## 五、如何构建 APK

本项目已配置 GitHub Actions，无需本地安装 Android Studio。

1. 打开仓库的 [Actions 页面](https://github.com/xiaosi555/deskops-apk/actions)。
2. 选择 **Build Android APK** 工作流。
3. 点击 **Run workflow**，选择 main 分支并启动。
4. 等待构建任务完成，确认状态为绿色 **Success**。
5. 打开本次运行记录，在 **Artifacts** 区域下载 deskops-debug-apk。
6. 解压下载的 ZIP，取得 app-debug.apk，传到 Android 手机安装。

每次向 main 分支提交代码也会自动触发构建。Debug APK 用于测试和个人安装，不等同于已签名发布版。

## 六、当前构建与测试状态

- GitHub Actions 自动构建流程已配置。
- APK 需要以 Actions 中实际成功的构建结果为准。
- 构建成功只代表 APK 已编译和打包，不等于所有手机型号、系统语音引擎、文件夹授权和媒体播放场景均已完成真机验证。
- 首次安装后建议检查：应用能否启动、页面是否完整显示、课程导航是否可点击、学习记录是否保存、文件导入是否可用、朗读与媒体播放是否符合设备能力。

## 七、项目定位

本应用主要用于桌面运维知识学习、IT 支持技能训练、个人学习进度管理与运维知识沉淀。它是学习辅助工具，不会自动连接或管理企业域控、终端设备、网络设备，也不会代替真实生产环境中的运维操作与权限审批。
